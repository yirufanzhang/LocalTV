# LocalTV 使用文档

LocalTV 是跑在你自己电脑上的创作页。浏览器里选模型、填参数，用你自己的火山方舟 API Key 调用 Seedream 生图、Seedance 生视频。计算在方舟完成，提示词、参考图和成片留在本机。

没有 LocalTV 账号。费用走你的方舟账户，每次生成都会扣额度。

当前版本 `0.1.0`。能直接生成的只有火山方舟。MiniMax 和可灵可以先把密钥存下来，模型还没接入，页面上会标「即将接入」。

## 环境

- Python 3.10 或更高
- 能访问火山方舟的网络
- 浏览器

页面只监听本机，默认地址是 http://127.0.0.1:8787 。「选择文件夹」「打开图片」「打开视频」「在访达中显示」是 macOS 上的行为：图片用预览打开，视频用 QuickTime 打开。其他系统请到成片目录里自己打开文件，存储位置在设置里填写绝对路径。

## 安装并启动

在项目目录里执行：

```bash
./start.sh
```

Windows 双击 `start.bat`，或在项目目录里运行它。第一次会创建 `.venv` 并安装依赖，之后再运行就是直接启动。macOS 上脚本会打开浏览器。关掉这个窗口，页面就停。

也可以自己装：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m localtv
```

Windows 激活虚拟环境用 `.venv\Scripts\activate`。

换端口或监听地址：

```bash
LOCALTV_HOST=127.0.0.1 LOCALTV_PORT=8787 python -m localtv
```

不要把 `LOCALTV_HOST` 改成 `0.0.0.0` 后再暴露到公网。密钥和成片都在这台电脑上，页面没有登录。

## 第一次使用

1. 打开页面，点右上角「设置」。
2. 在「火山方舟」里粘贴 API Key。接口保持默认即可：`https://ark.cn-beijing.volces.com/api/v3`。只填到 `/api/v3`，不要填具体的图片或视频接口。
3. 保存。页面上只会显示密钥末尾四位。
4. 回到「图片」或「视频」，写提示词，点生成。

Key 在[火山方舟控制台](https://console.volcengine.com/ark)创建。没有 Key，生成按钮不可用。

密钥写在 `~/.localtv/config.toml`，文件权限是 `0600`（只有当前用户可读写）。不要把这个文件提交到 git，也不要贴到 Issue 里。环境变量 `ARK_API_KEY` 会盖过文件里的方舟密钥。

留空再保存不会清掉已经存好的 Key。要清除某一家的密钥，用设置里对应的清除按钮。

## 页面怎么排

左侧三个入口：

| 入口 | 做什么 |
| --- | --- |
| 项目 | 看这个项目里的图片和视频，新建项目，切换当前项目 |
| 图片 | Seedream 生图 |
| 视频 | Seedance 生视频 |

中间上面是画布，生成结果出现在这里。下面是生成器：先选厂商和模型，再选任务，然后写提示词、加参考素材。右侧是参数。和模型默认值一样的项不会发给方舟；你改过的才会提交。生成器底部可以展开「查看这次实际提交的字段」核对。

快捷键是 `⌘/Ctrl + Enter`。

「新对话」只清空当前这一侧的提示词、参考素材和画布，模型和其他参数留着。已经生成的文件还在项目里。

灰色的任务或参数是当前模型不支持的，旁边有原因。即将下线的模型名称上会标明。

## 生图

默认模型是 Seedream 5.5。可选 5.0 pro、5.0 flash，以及即将下线的 5.0 lite、4.5、4.0。

| 任务 | 怎么用 |
| --- | --- |
| 文生图 | 只写提示词。也可以再上传参考图，模型会一起看 |
| 图生图 | 先上传要改的图，提示词写改什么、留什么 |
| 组图 | 一次出一组相关图。目前只有 Seedream 5.0 lite 可以选 |
| 图层拆分 | 把一张 png 或 jpeg 拆成图层 |

参考图是本地 png、jpeg，可多选，单张不超过 30MB。图片水印默认开启，成片右下角会有「AI 生成」，不想要就在右侧关掉。

常用尺寸在生成器底部：方图、横图 16:9、竖图 9:16、只选 2K。更细的档位、比例、自定义宽高、输出格式和透明通道在右侧。选了比例时，LocalTV 按该模型文档里的像素表提交宽高。

生成完成后，画布上可以打开图片、在访达中显示，或「接着做视频」。接着做视频会把这张图带进视频页的参考素材。

## 生视频

默认模型是 Seedance 2.5 flash，分辨率到 720p，时长 4–30 秒。要更高分辨率用 Seedance 2.5。2.0 系列时长是 4–15 秒。1.0 系列即将下线。

| 任务 | 怎么用 |
| --- | --- |
| 文生视频 | 写镜头。本地参考图可以直接选 |
| 首帧 | 上传第一帧图片 |
| 首尾帧 | 上传开始和结束两张图 |
| 全模态参考 | 图、视频、音频一起做参考。参考视频必须是公网地址，方舟读不到你电脑上的文件 |
| 编辑视频 | 在已有视频上改。需要参考视频的公网地址 |
| 延长视频 | 把视频往后接 |
| 样片转正式 | 只有 Seedance 2.5 标准版可以开样片模式 |

视频水印默认关闭。声音默认生成；想让角色说话，把台词放在双引号里。第一次试片用 720p、指定 5 秒或 10 秒即可。

视频是异步的。提交后页面会等方舟，完成后自动下载到当前项目。生成过程中不要关掉运行 LocalTV 的终端。

## 项目和成片放在哪

默认目录是文稿里的 `LocalTV`，也就是 `~/Documents/LocalTV/`。设置里可以改。改的时候，已有项目会一起搬过去。密钥仍留在 `~/.localtv/config.toml`，不会跟着成片走。

每个项目是一个文件夹：

```text
~/Documents/LocalTV/
  default/
    project.json
    inputs/                 本次任务用过的参考图
    jobs/                   每条任务一条记录
    outputs/<任务 id>/      图片或 video.mp4
```

右上角点项目名可以直接切换当前项目。左侧「项目」页按图片、视频分组，用来浏览成片和新建项目。点「查看」回到对应的图片或视频页，把这条结果显示在画布上。点「在此项目中创作」把它设为当前项目，并回到创作页。

`LOCALTV_LIBRARY` 如果设了，存储位置以它为准，设置里不能再改。`LOCALTV_HOME` 可以改配置目录，默认是 `~/.localtv`。

## 其他服务商

设置里可以分别保存 MiniMax 和可灵的接口与密钥，互不影响。

| 服务商 | 环境变量 | 默认接口 |
| --- | --- | --- |
| 火山方舟 | `ARK_API_KEY` | `https://ark.cn-beijing.volces.com/api/v3` |
| MiniMax | `MINIMAX_API_KEY` | `https://api.minimaxi.com`（国际密钥用 `https://api.minimax.io`） |
| 可灵 | `KLING_API_KEY` | `https://api-beijing.klingai.com`（海外用 `https://api-singapore.klingai.com`） |

可灵新版控制台填 API Key；旧版开放平台填 Access Key 和 Secret Key。环境变量会盖过文件里的对应密钥。

选到还没有模型的厂商时，生成按钮不可用，页面会提示还没有接入。

## 参数怎么提交

页面把该模型公开的参数都列出来。规则是：

- 模型和支持的任务一定会发。
- 和官方默认值相同的字段不发。
- 你改过的字段按页面上的值发。
- 当前模型不支持的字段留在页面上，但是禁用，不会偷偷丢弃你填过的值。

所以「查看这次实际提交的字段」里通常比右侧表单短。这是预期行为。

## 常见问题

**生成按钮是灰的。** 当前厂商没有密钥，或提示词、参考素材还没满足任务要求。看生成器里的红字。没有接入模型的厂商也不能生成。

**提示密钥无效或余额不足。** 这是方舟账户的问题。检查 Key、账户额度和模型是否已开通。LocalTV 不会显示完整 Key。

**参考视频传不上去。** 视频不能选本机文件，要填方舟能访问的公网 URL。图片可以选本地文件。

**成片不在我选的文件夹。** 看设置里的存储位置，以及有没有设置 `LOCALTV_LIBRARY`。页面上的路径在文稿目录下时会显示成「文稿/…」。

**打开视频进了别的播放器。** 在 macOS 上，页面里的「打开视频」指定 QuickTime。访达里双击仍走系统默认播放器。

**换了存储位置，旧文件还在不在。** 从设置里保存新位置时，已有项目会搬过去。只改环境变量不会自动搬家。
